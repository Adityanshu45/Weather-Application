
## ⚡ How It Works
1. Enter a city name in the search bar.  
2. App fetches weather data from **OpenWeather API**.  
3. Displays weather details:  
   - Temperature 🌡️  
   - Humidity 💧  
   - Wind Speed 🌬️  
4. Handles errors gracefully if the city is not found.
